# Каталог кадров машин

Рецепт целиком — [docs/CATALOG.md](../../../docs/CATALOG.md). Он не
обсуждается и не улучшается по ходу: так сделаны 76 кадров прода, и
пользователь считает их эталоном. 2026-09-15 агент собрал свой конвейер
вместо этого и сжёг около $2.50 впустую.

## Перед первым платным запросом

1. Прочитать `docs/CATALOG.md` целиком и запись журнала за 2026-09-06.
2. `python3 tools/catalog_openrouter.py --dry-run`: образец у каждой
   машины должен быть `CarPhoto`, не кадр другой машины.
3. `--limit 2`, открыть рядом с любым `.heic` из каталога: та ли машина,
   целые ли шины, есть ли отражение под порогами, вправо ли морда.
4. Только потом весь бюджет.

## Никогда

- Образец «той же марки и кузова» — модель копирует машину, а не стиль.
- `--floor` больше нуля — срезает шины и отражение.
- Проверка краёв по сырью — двойной счёт.
- Сборка поверх сырья — переделать будет не из чего.
- Правка `MASTER_PROMPT`.
- Весь бюджет до взгляда на два кадра.

## После генерации

`tools/catalog_import.sh` → `python3 tools/check-catalog.py` должен сказать
«всё сходится» → контактный лист партии рядом с четырьмя старыми кадрами,
глазами → коммит HEIC. Правило в `CarCatalog.swift` без файла рисует
пустую подложку: правило и файл едут парой.
