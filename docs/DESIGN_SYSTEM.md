# Дизайн-система Beepy

Собирается постепенно (решение пользователя 23.10.2026): повторяющийся кусок
интерфейса становится компонентом в `AppMVP/Core/Design/Components`, его
копии в экранах заменяются им, а сам компонент рисуется в Figma на странице
«14 Дизайн-система Beepy». Этот файл — перечень и правила; подробности у
каждого компонента в его комментарии.

## Правила

1. **Второе появление — повод сделать компонент.** Одинаковая вёрстка в двух
   экранах расходится при первой же правке одного из них: так номер на экране
   поездки и стал строкой на другой подложке.
2. **Числа — токены.** Цвета — `Figma` в `Core/Design/Theme.swift`, движение —
   `Motion` в `LiquidGlass.swift`, размеры компонента — его вложенный
   `enum Layout` (или общий, как `GroupedLayout`). Литерал в вёрстке экрана —
   только строка.
3. **Компонент не знает про данные.** Принимает значения (`String`, `Bool`,
   замыкание), а не `Car` или `Trip`: переходники остаются в экранах, логика —
   в `Core/Pure`.
4. **Доступность — внутри компонента.** Подпись, значение и признак кнопки
   ставит сам компонент: экран не должен помнить об этом в каждом месте.
5. **Компонент — сразу в Figma**, на страницу дизайн-системы, слоями. Новый
   экран собирается из них же.

## Основа

| Что | Где |
|---|---|
| Цвета и типографика макета | `Figma` — `Core/Design/Theme.swift` |
| Движение: пружины, длительности | `Motion` — `Core/Design/Components/LiquidGlass.swift` |
| Стекло с фолбэком до iOS 17 | `.liquidGlass(in:tint:kind:fallback:)` — там же |
| Блик кромки по наклону | `.motionRim(in:)` — `MotionRim.swift` |
