правок смотри в коммитах. Здесь то, что из истории не восстановить: принятые

## Принятые решения

| Решение | Почему |
|---|---|
| Хранение локальное, на SwiftData | 152-ФЗ: приложение для РФ, Supabase хостится вне России. Пока данные не покидают телефон, обязанностей оператора ПДн нет |
| Supabase удалён целиком | Он не работал: экраны авторизации были недостижимы из `RootView`, схема на сервере шаблонная (`profiles`, `items`) |
| Наличие машины выводится из базы | Раньше был флаг `hasAddedCar` в `UserDefaults` — он разъезжался с данными |
| Ключ поставщика поиска по госномеру — только на сервере | Ключ в `.ipa` достаётся за минуты, за него спишут баланс платного API |
| Системное стекло важнее совпадения с растром Figma | Макет сам ссылается на системный компонент `Liquid Glass`, растр — лишь его приближение |
| Блик по наклону — своя реализация на CoreMotion | Публичного API нет: у `Glass` только `regular/clear/identity/tint/interactive`, у `UIGlassEffect` — `interactive/tintColor` |
| Свайп карусели только в верхней зоне (620pt) | Снимает конфликты жестов с вертикальным скроллом и лентой ТО, которые ломали экран несколько раз |
| Кнопки подняты над home indicator | В Figma home indicator не нарисован, макет доходит до края экрана, и кнопки заезжали на него даже на макетном устройстве |

## Грабли (механизмы, а не симптомы)

- **`.background` не раздувает родителя, а сосед в `ZStack` — раздувает.**
  Градиентный слой требует 1534pt; как сосед он растянул контейнер, `ScrollView`
  получил вьюпорт 1534, контент влез целиком и **скролл исчез**. Верх экрана
  при этом выглядел правильно, поэтому сверка кадров молчала.
- **Чтение окна UIKit в `body` даёт цикл AttributeGraph.** `body` начинает
  зависеть от размера окна, а тот — от раскладки `body`. Граф замыкается,
  вьюхи перестают перерисовываться, и это выглядит как «нажатия не работают».
  Размеры экрана берутся из `DeviceMetrics` через окружение.
- **`Task {}` во вьюхе наследует MainActor.** `UIImage(data:)` на полном кадре
  вешал интерфейс на секунды. Декодирование вынесено в `ImageLoader` через
  ImageIO вне главного актора, с уменьшением до 1200px.
- **`DragGesture(minimumDistance: 0)` глушит скролл в своей области** —
  перехватывает касание до начала движения.
- **Контрол внутри ветки, которой он управляет, уничтожается при переключении**
  вместе с нажатой кнопкой и своим `@Namespace` — так ломался сегментед-контрол.
- **Флаг состояния жеста может залипнуть**, если `onEnded` не пришёл (жест
  отменён скроллом). `.scrollDisabled` на таком флаге выключил скролл навсегда.
- **`@State`, который пишут на каждом кадре прокрутки, ломает сам скролл.**
  Смещение прокрутки лежало в `@State` и читалось в `body` (прозрачность
  шапки). `body` стал зависеть от позиции, `ScrollView` пересобирался на
  каждом кадре, и экран **сам уезжал на 151pt вниз** — шапка «появлялась»
  в покое, а `cycle detected` в консоли не было. Лечится тем, что позиция
  вообще не становится состоянием вью: прозрачность считает `.visualEffect`
  (эффект этапа отрисовки, читает геометрию без инвалидации `body`), а для
  жеста значение лежит в ссылочной коробке, которую никто не наблюдает.
- **Замыкание `.visualEffect` помечено `@Sendable`** и не может читать
  статики, изолированные главным актором, — константы пришлось вынести
  из вью в отдельный `enum` на уровне файла.
- **Токен из Figma может не совпадать с тем, как нода отрисована.** Стиль
  Headline объявляет трекинг −0.43, но ширина ноды заголовка шапки (208)
  равна ширине строки **без** трекинга (208.02); с −0.43 вышло бы 197.
  Мерить надо отрисованную ноду, а не доверять токену.
- **Сборка внутри папки проекта не подписывается.** Рабочий стол синхронизируется
  с iCloud, файловый провайдер вешает `com.apple.FinderInfo`, codesign падает с
  `resource fork ... not allowed`. Собирать в `~/Library/Developer/Xcode`.

## Как проверять (обязательный минимум)

1. Сборка без предупреждений.
2. Консоль симулятора: **нет `cycle detected`**.
3. **Скролл жив**: временно `.defaultScrollAnchor(.bottom)` — кадр должен
   показать низ страницы с «Удалить авто». Этот замер один раз поймал регрессию,
   которую не видела попиксельная сверка.
4. Попиксельная сверка с рендером Figma. Ориентиры: главный экран ~8.7/255,
   экран добавления 5.9/255, шторка «Это ваш автомобиль?» 15.2/255.
5. Симулятор перед съёмкой **перезагружать**, кадр снимать **до** остановки
   процесса, прокрутку сбрасывать. На каждом из этих трёх пунктов уже были
   ложные результаты.
6. **Рендеры Figma перекачивать**, если дизайн правился. Дважды сверялся с
   устаревшими и объявлял совпадение там, где его не было.

## Статичная карусель (сделано)

Подложки при свайпе должны **оставаться на месте**, меняться должен только
текст — как в Гараже Т-Банка. Аннотация макета `45895:3569` говорит то же
самое: «все элементы остаются на месте и просто меняются надписи». Она
процитирована в `CarMainView.swift:127`, но построено было противоположное —
`HStack` из двух полных страниц со сдвигом `.offset(x:)`.

**Из этой архитектурной ошибки выросли все недавние баги:** конфликт жеста с
вертикальным `ScrollView` и с лентой ТО, обнажение фона за краем, подложка
под каруселью, раздутый вьюпорт и пропавший скролл, залипший `.scrollDisabled`.
В статичной раскладке ничего этого не существует — двигать нечего.

Целевая архитектура: одна неподвижная страница, прогресс свайпа `p` (0…1)
управляет только содержимым.

- фото машины — единственный едущий элемент: два кадра в ряд со сдвигом
  `p × ширина`, обрезанные по рамке 190.415pt;
- общие подложки (тёмная карточка 92pt, radius 36) стоят, лейблы внутри
  перекрёстно гаснут: «Добавить ТО» → «Добавить авто»;
- заголовок и номер на месте, текст меняется, номер гасится в 0;
- блоки только первой страницы (stat-карточки, история, удаление) гаснут
  целиком при `p → 1`;
- пейдж-контрол уже неподвижен, не трогать.

Удаляется: `HStack` двух страниц и `.offset(x:)`, `pinX` и компенсация точек,
резинка на краях (`dragX / 10`, `atEdge`), `swipeZoneHeight` как защита от
конфликтов, `addNewCarState` как отдельная страница. Остаётся: `carPage`,
`dragX`, замок оси, `Motion.page`, параметр `visible` в построителях карточек
(в него пойдёт `1 - p`).

Проверять: подложки **не сдвинулись ни на пиксель** между кадрами при
`p` = 0, 0.5, 1 — численно через `rowsx`, не на глаз. Плюс обязательный
контроль скролла через `.defaultScrollAnchor(.bottom)`.

Сделано в `955aab4`; в `d838246` починен лейаут (блок фото сообщал наверх
402pt внутри контентных 370 и вылезал за края на 16 с каждой стороны — теперь
он в локальном `GeometryReader`, который принимает предложенную ширину).

## Шапка при прокрутке и запрет свайпа (сделано)

Свайп карусели запрещён, когда список прокручен дальше 8pt: у жеста один
предикат `canSwipe(startY:)` на `onChanged` и `onEnded`. Если жест начался
разрешённым, а список успел уехать за порог, `onEnded` возвращает `dragX`
в ноль — иначе страница залипала наполовину погашенной.

Шапка — нода `46001:6457`: чёрная плашка 402×137 от самого верха кадра
(вместе со статус-баром), контент прижат к низу, номер в ней **мельче**
основного (11pt против 17, паддинги 6/2 против 12/4) — это отдельный
`compactPlate`, а не тот же `plate`. Лежит оверлеем **внутри** прокрутки и
приколочена к верху обратным сдвигом через `.visualEffect` — см. грабли выше
про `@State`. Сверка с рендером ноды: **1.7/255**, зон расхождения нет.
Экран в покое побитово совпал с предыдущим коммитом (0.0/255).

## Технический долг

- Свайп по ленте истории ТО двигает всю страницу — жест, который это чинил,
  глушил прокрутку и был снят. Переделать без перехвата касания.
- Резинка на краю карусели очень короткая (`dx/10`) — компромисс вместо
  подложки, которая трижды ломала экран.
- Затухание надписей не проверено визуально: симулятор завис на съёмке кадра.
- Реального парсера PDF и фото для ТО нет — заглушка `applyParsedService`.
- Поиск по госномеру — заглушка `StubVehicleLookup`, находит любой корректный
  номер. Состояние «не нашли номер» не воспроизводится.
- Тестового таргета нет. Жесты и касания проверить нечем — отсюда несколько
  правок вслепую и регрессий. `PlateFormat` намеренно чистый энам под тесты.

## Ограничения окружения

- Тапать по симулятору нельзя: macOS не даёт доступ `/usr/bin/osascript`
  в «Универсальном доступе». Любое поведение жестов проверяет пользователь.
- Гироскопа в симуляторе нет — блик по наклону проверяется только на устройстве.
- Профиль бесплатного Apple ID живёт 7 дней, после чего приложение надо
  переустановить. Команды — в `docs/DEVICE_TESTING.md`.
