# Apple Developer Program — актуальное состояние 14.11.2026

Beepy подписывается платной командой **5BK4R35RB8**, bundle ID
`com.vladislavkotyrev.appmvp`. Sign in with Apple включён и проверен владельцем
на физическом iPhone. Повторная регистрация или оплата для этого выпуска
не требуются: Release archive и загрузка сборки 11 выполнены успешно.

Вход текущего выпуска локальный: системная AuthenticationServices,
идентификатор/сессия в Keychain, без запроса имени/почты и без сервера аккаунтов.
Выход и удаление локальных данных находятся в «Ещё»; после удаления есть
инструкция ручного отзыва доступа Apple. Не заявлять серверную проверку
или автоматический отзыв токенов: они не реализованы в этом выпуске.

Статус карточки, видео и повторной отправки: [APPSTORE.md](APPSTORE.md).
Доступность веб-сессии App Store Connect проверять отдельно от аккаунта Xcode.
