2. Purpose and audience
Beepy is a free personal car journal for the general public: vehicle maintenance, mileage, trips, nearby service locations and preliminary engine-sound analysis on iPhone. It helps owners keep records and decide what to discuss with a mechanic. Analysis is not a professional inspection or a guarantee of vehicle safety.
No paid features, subscriptions, in-app purchases, ads, public user content, messaging or business-only access. Private records are not shared with other users.

3. Setup and main features
Use the system Sign in with Apple button with your Apple Account. No separate Beepy username/password, invitation or approval is needed. Name/email are not requested. No sample files or additional accessories are required.
Complete the three onboarding pages. Optional GPS can be skipped with “Позже” (Later). For automatic background mileage choose Always location access; otherwise continue without automatic recording.
Add a car manually by name. “Машина” (Car) holds mileage, maintenance records and service intervals. License-plate lookup, market-price lookup and cloud sync are disabled in this release. Manual entry has no car-count limit.
“Карта” (Map) shows service locations and favorites using Yandex Maps; internet is required. With location enabled, the car selected for automatic mileage is the position marker.
“Диагностика” (Diagnostics): allow microphone access and follow the recording instructions. Use actual engine sound for a meaningful result. Analysis runs on device.
“Ещё” (More) contains trip/automatic-mileage settings, sign-out and “Удалить аккаунт и данные” (Delete account and data). Tracking is optional and uses background location when enabled.
Deletion removes the local Apple session and local vehicle, trip, maintenance, diagnostic and favorite-place records. The app then links to Apple's instructions to revoke Sign in with Apple access manually. No Apple refresh/access token is stored and there is no Beepy account server. Automatic token revocation is not claimed. See Apple's TN3194 manual-revocation guidance and the attached explanation.

4. External services
Apple Sign in with Apple and Keychain: authentication/local session. Yandex MapKit: map display, search, geocoding. Apple Core Location: optional trip tracking. Apple Core ML: on-device sound analysis. GitHub Pages: support/privacy pages. No cloud AI receives engine recordings. Generative AI was used only to prepare bundled artwork, not as an in-app service.

5. Regions
No region-specific feature gates. The interface is Russian. Map/search coverage depends on Yandex and authentication availability on Apple. The disabled server features above are disabled in every region.

6. Services and third-party materials
