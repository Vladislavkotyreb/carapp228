# Каталог кадров машин — рецепт, который уже работает

Единственный источник правды о том, как делаются студийные кадры машин в
`AppMVP/Resources/CarCatalog/`. Читать **до** любой генерации, которая
стоит денег. 2026-09-15 агент этот рецепт не прочитал, собрал свой и сжёг
около $2.50 пользователя на 65 кадров, из которых ни один не пошёл в дело.

**2026-10-13 выяснилось, что до этого дня здесь был записан не тот
рецепт.** Таблица ниже раньше описывала v2 (образец `CarPhoto`,
`MASTER_PROMPT`, вырезка Vision, синтетический пол `compose_hero`). Но v2
прожил полдня: вечером 2026-09-06 v3 заменил все 75 кадров (коммит
`47c85a0`, 75 HEIC), и в приложении стоит именно v3. А `CarPhoto` с
2026-09-07 — машина под покрывалом, не RX. Партия 2 (2026-09-15) шла по
старой таблице, и пользователь забраковал её по листу: «пола нет с
отражением». Второй ряд того же листа (прод v3) — «оч сексуально».

## Рецепт прода — v3 (2026-09-06, 75 кадров + жираф)

| Шаг | Что именно | Где в коде |
|---|---|---|
| Модель | `google/gemini-3.1-flash-image` через OpenRouter | `PROD_MODEL` в `tools/catalog_openrouter.py` |
| Референс | Lexus RX на чёрном: `~/beepy-catalog/reference.png` (RX 1251×832 из экспорта пользователя, есть только на маке); без него — кадр `lexus-rx` из каталога. **Не `CarPhoto`**: это покрывало | `prod_reference()` |
| Промпт | «Recreate the reference EXACTLY… only the car itself changes» + строка машины из списка. Полный текст в журнале не сохранился — `PROD_PROMPT` держит обе фразы дословно, середина восстановлена. Оригинал лежит в транскрипте сессии 06.09 на маке: `grep -rhoE 'Recreate the reference.{0,1500}' ~/.claude/projects \| sort -u` | `PROD_PROMPT` |
| Формат | 3:2 на выходе модели (`image_config.aspect_ratio`), ширина 1264 — как у всех кадров v3 | `generate()` |
| Обработка | **Никакой.** Тень и отражение под машиной рисует модель — именно их нет у партии 2. Кадр только обрезается до **1264×841** (у 3:2 лишние строки поровну сверху и снизу) | `fit_prod()` |
| Ориентация | Морда вправо, как у референса. v3 нарисовал влево один Polo из 75; лечится бесплатно `--recompose --flip --only a,b` | сырьё `<slug>.raw.png` |
| Валидатор | периметр кадра ≤ 26 по яркости (`edges_are_black`); у v3 одна попытка, кадр со светлыми краями — в список «глазами» | `--attempts`, по умолчанию 1 |
| Повтор по форме | Если модель перерисовала RX (у v3 так было с Duster и Niva Travel), лечится подсказкой формы в строке машины («boxy upright…»), не правкой промпта | `prompt` в списке машин |
| Связь | Ответ тянется `curl`, без автоповтора: на обрыве генерация на сервере проходит и списывается (журнал 2026-09-07) | `post_curl()` |
| Куда | `~/beepy-catalog/v3` — отдельно от `raw`, где лежат PNG первой партии с чужими машинами | `PROD_OUT` |
| В проект | `tools/catalog_import.sh` (сам берёт `v3`): `sips … formatOptions 80`, без мака — pillow-heif с тем же качеством | `to_heic` |
| Правила | слаг ↔ название в `CarCatalog.swift`; правило без файла рисует пустую подложку | `tools/check-catalog.py` |

Цена v3 по факту: $5.09 за 75 кадров, около **$0.068 за кадр** (журнал
2026-09-06). Весь второй список (65 машин) — около $4.42.

## Порядок работы, обязательный

1. `python3 tools/catalog_openrouter.py --dry-run` — рецепт, модель,
   образец, промпт целиком, оценка.
2. Два кадра — лучше те, где модель скорее всего перерисует образец:
   `--only toyota-camry-40,kia-soul`. Открыть рядом с `lexus-rx` и
   любыми двумя кадрами v3. Смотреть: **та ли машина**, есть ли глянцевый
   пол с отражением, тот ли ракурс сверху, вправо ли морда.
3. Только после этого — весь бюджет: `--budget 4.60`. Сырьё лежит рядом,
   зеркало и обрезка бесплатны: `--recompose`.
4. Контактный лист всей партии рядом с четырьмя кадрами v3 — глазами.
   Не та машина — `--only <слаг> --force` с подсказкой формы в списке.
5. `tools/catalog_import.sh --force`, `python3 tools/check-catalog.py`,
   правила из `e541307` для 53 убранных слагов, коммит HEIC.

## Чего не делать (каждый пункт уже стоил денег)

- **Не подбирать образец «той же марки и кузова».** Nano Banana копирует
  из образца машину, а не свет: под именем Camry XV40 вышла семидесятая,
  под Pajero — УАЗ, под Outback — Веста SW. Так испорчено 40 из 65.
- **Не брать образцом `CarPhoto`.** С 2026-09-07 это машина под
  покрывалом: с неё переносится низкая камера и пол без отражения, вся
  партия 2 ушла в брак.
- **Не вырезать машину и не подкладывать синтетический пол под v3.**
  Отражение под машиной — то, за что пользователь ценит прод; вырезка
  его снимает.
- **Не прижимать фон к чёрному перед сборкой.** Срезает шины и отражение.
  Так испорчены все 65. Журнал за 06.09 это уже запрещал.
- **batch2: не проверять края у сырья.** У сырья `MASTER_PROMPT` они
  светлые всегда; проверка по нему браковала бы каждый кадр и удваивала
  счёт. У v3 сырьё и есть итоговый кадр — проверяется оно.
- **Не выбрасывать сырьё.** Первая версия генератора писала сборку поверх
  него; когда сборка оказалась неверной, переделать было не из чего.
- **Не тратить весь бюджет до взгляда на два кадра.**
- **Не менять промпт v3 на глаз.** Нашёлся оригинал в транскрипте на
  маке — заменить `PROD_PROMPT` им целиком; не нашёлся — менять только
  строку машины.
