BEEPY — MAP SERVICE AND VEHICLE ILLUSTRATIONS
Updated 14 November 2026 for App Review, app version 1.0.0 (11).

1. Yandex Maps
Beepy uses the official Yandex MapKit SDK for map display, place search and geocoding. The developer's API console was inspected on 8 November 2026: MapKit SDK was Active, on the Free plan. The console displayed 2 out of 1,000 requests used that day. No plan change or purchase was made.
Applicable public terms:
https://yandex.ru/legal/maps_api/ru/
https://yandex.ru/legal/maps_termsofuse/ru/

Beepy is a free public app. The latest source changes add tappable links to both terms under More > About. Geocoded trip addresses use a 29-day cache; expired entries and legacy entries without a retrieval date are cleared at launch/foreground and during active use. Expired addresses are excluded when creating trip display data. Trip distances and user-recorded route coordinates are not removed by this cache cleanup. iOS cannot run cleanup while the app is suspended; it resumes at the next activation.
These corrections were introduced in build 5 and are included in build 11; build 4 did not include them.

Its final 6 September generation entry records Gemini/Nano Banana via OpenRouter; later entries document further generation batches. Local original PNG outputs are retained. Earlier records also describe Kandinsky experiments/batches; the audit does not certify the exact model used for each individual shipped file.

The developer explicitly confirmed on 8 November 2026 that the original Lexus reference was also generated by them with Nano Banana. This is a developer-provided provenance statement, not a licence certificate issued by a car manufacturer. 4. Sign in with Apple and deletion
The app stores only a local Apple user identifier/session in Keychain. It does not retain Apple authorization codes, access tokens or refresh tokens, and has no active account backend. More > Delete account and data deletes local records and the Keychain session, returns to onboarding, and links to Apple's manual revocation instructions. The app observes credentialRevokedNotification and checks credential state when active.
Apple TN3194 describes manual revocation where tokens/authorization code are unavailable: delete account data, direct the user to revoke access, and respond to revoked credentials. This document reports the implemented behavior; it does not claim automatic server-side revocation or guarantee App Review acceptance.
https://developer.apple.com/documentation/technotes/tn3194-handling-account-deletions-and-revoking-tokens-for-sign-in-with-apple
https://support.apple.com/102571
