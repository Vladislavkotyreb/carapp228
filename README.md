# Beepy

**Дневник машины для iPhone: слушает мотор, сам считает пробег и напоминает про ТО.**
Рядом — сервер в России и веб-CRM для автосервисов.

![Beepy на iPhone: главная, онбординг, диагностика](docs/readme/ios.jpg)

## Возможности

- **Диагностика по звуку.** Запись мотора разбирается прямо на телефоне, без
  сети. Сначала проверка, мотор ли это вообще, потом калиброванная вероятность
  неисправности и узлы, на которые стоит посмотреть.
- **Автопробег.** Приложение замечает поездку, даже закрытое, и прибавляет
  километры к пробегу. С привязкой к Bluetooth машины поездки на такси в пробег
  не попадают.
- **ТО.** История с суммами и пробегом, «ТО через N км», напоминание и запись в
  ближайший сервис.
- **Машина по госномеру** — марка, модель, VIN и рыночная цена.
- **Карта** СТО и шиномонтажей на Яндекс Картах.
- **Beepy для бизнеса** — CRM автосервиса: заявки списком и канбаном, склад с
  расходом по норме, сотрудники, палитра команд ⌘K.

![Beepy для бизнеса: заявки автосервиса](docs/readme/crm.jpg)

## Как устроено

- **Разбор звука на устройстве.** Пайплайн LAION CLAP с головами
  [car-diagnosis](https://github.com/adam-s/car-diagnosis) переведён в Core ML:
  мел-фронтенд в fp32 (у спектра динамический диапазон около 200 дБ, fp16 его
  не держит), энкодер в fp16. Со своим Python-сервером сходится до 0.0002.
- **Поездки в фоне.** Закрытое приложение будят выход из гео-зоны стоянки и
  «значимое перемещение». CoreMotion отличает машину от прогулки, маршрут звука
  через `AVAudioSession` — свою машину от такси. Старт и стоп доступны из
  «Быстрых команд» (App Intents).
- **Чистый слой.** Логика без SwiftUI, SwiftData, диска и сети живёт в
  `AppMVP/Core/Pure` и собирается отдельно через `swiftc`. Её проверки идут без
  Xcode, а импорт UIKit в этот слой ломает сборку сразу.
- **Данные и 152-ФЗ.** Машины, ТО и маршруты хранятся на телефоне в SwiftData.
  Сервер нужен только для поиска по номеру и цены: платный токен поставщика
  остаётся на сервере, госномер и VIN там не хранятся, журнал запросов живёт
  90 дней. Манифест приватности собран по импортам бинарника.
- **Интерфейс.** Экраны воспроизводят макеты Figma попиксельно, со сверкой
  кадров. Liquid Glass с фолбэком до iOS 17, «облако» прослушивания — шейдер
  Metal.
- **Каталог машин.** 181 кадр поколений популярных в России моделей,
  сгенерированных по одному рецепту; машина подбирается по названию и году.

## Стек

| | |
|---|---|
| iOS | Swift, SwiftUI, SwiftData, iOS 17+, Core ML, CoreLocation, CoreMotion, AVFoundation, App Intents, Metal, Yandex MapKit, XCTest |
| ML | LAION CLAP → Core ML (coremltools), Python-сервер для сверки |
| Сервер | TypeScript, Node 22, Hono, Postgres (PGlite в тестах), zod, Docker |
| CRM | React, TypeScript, Vite, Tailwind, shadcn/ui, framer-motion |
| Дизайн | Figma |

## Структура

```
AppMVP/          iOS-приложение: Features/, Core/Pure/, Core/Services/, Models/
BeepyTests/      юнит-тесты: база, восстановление, бандл
BeepyUITests/    UI-тесты ключевых флоу
server/          поиск по номеру, цена, политика конфиденциальности, админка
crm/             веб-CRM для автосервиса
tools/           проверки, конвертация модели, каталог машин
docs/            состояние, решения, журнал
```

## Запуск

```bash
open Beepy.xcodeproj        # схема AppMVP, ⌘R на симуляторе
npm --prefix server test    # сервер, Postgres ставить не нужно
npm --prefix crm run dev    # CRM на localhost
```

На своём iPhone — [docs/DEVICE_TESTING.md](docs/DEVICE_TESTING.md).

## Проверки

```bash
tools/test-all.sh           # без Xcode — SKIP_XCODE=1
```

563 проверки чистого слоя, типографика строк, целостность проекта, 28 тестов
сервера и XCTest на симуляторе: 11 юнит-тестов и 4 UI-теста.
