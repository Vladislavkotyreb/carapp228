# Прокси Beepy на ProfitServer

Размещение: `/opt/beepy/deploy`, Ubuntu 22.04, Челябинск, VPS №1437575.
Адрес приложения: https://80.85.156.31.
У выданного провайдером имени нет публичной A-записи на момент переноса.
Для IPv4 Caddy получает публичный сертификат Let's Encrypt по профилю
`shortlived` и обновляет его автоматически. `default_sni` позволяет
предъявлять сертификат клиентам, подключающимся к IP без SNI. Том
`caddydata` хранит ключи и состояние ACME. Порты 80 и 443 должны быть
доступны для HTTPS и проверки адреса при обновлении сертификата.

Compose запускает Postgres, API и Caddy. БД и порт API не публикуются.
Доступны GET `/v1/health`, POST `/v1/installs` и
POST `/v1/vehicles/lookup`. Маршруты аккаунтов, синхронизации, оценки
стоимости и админки закрыты. Сервер не сохраняет госномера и VIN.

## Настройка и обновление

`deploy/.env` хранится на сервере с правами 600, каталог имеет права 700.
В образ, Git и приложение токен поставщика не включается. При первичной
настройке используйте `.env.example`, включая случайный пароль Postgres
из символов, допустимых в URL (например, hex).

Из `/opt/beepy/deploy`:

```sh
docker compose config --quiet
docker compose up -d --build --wait
curl --fail https://80.85.156.31/v1/health
```

Используйте `config --quiet`, чтобы не вывести секреты. Для обновления
копируйте только отслеживаемые файлы из каталога `server`. Сохраняйте
`.env` и тома Postgres и Caddy.

## Бюджет

`LOOKUP_DAILY_BUDGET_RUB=500`, `LOOKUP_UNIT_COST_KOPEKS=800`,
`LOOKUP_DAILY_FOUND=62`, `LOOKUP_PER_INSTALL_DAILY=10`.
Сервер атомарно резервирует до 62 вызовов по 8 ₽ за скользящие 24 часа
(496 ₽). Подтверждённое отсутствие результата освобождает резерв. Таймаут
и неизвестный исход сохраняют резерв на 24 часа. При росте цены уменьшите
предел до включения запросов.

Поставщик подтвердил лимиты 500 ₽/день и 5000 ₽/месяц. Они дополняют
проверку Beepy. Две сохранённые машины по номеру ограничивает приложение,
сервер считает запросы по токену установки. Серверной квоты по Apple ID нет.

Перед следующим переносом сохраните актуальный журнал отдельно от ВМ.
Если журнала нет, оставьте общий лимит 0 на 24 часа, чтобы не расходовать
тот же бюджет повторно. При настройке используйте только бесплатный
[номер из документации поставщика](https://avtovincod.ru/docs/gos2vin/).
