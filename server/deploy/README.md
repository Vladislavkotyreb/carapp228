# Прокси Beepy на Netcup

Размещение: `/opt/beepy/deploy`, VPS Ubuntu в Нюрнберге.
Адрес: https://v2202609418891520218.quicksrv.de

Compose запускает только Postgres, API и Caddy. БД и порт API не публикуются.
Внешний доступ: GET `/v1/health`, POST `/v1/installs`, POST `/v1/vehicles/lookup`.
Остальные маршруты, включая аккаунты, поездки, админку и оценку цены, закрыты
в Caddy и приложении (`VEHICLE_PROXY_ONLY=1`). Существующий Amnezia VPN
на VPS не входит в этот Compose-проект; не останавливать его и не перезапускать Docker.

## Настройка и обновление

`deploy/.env` хранится только на сервере с правами 600, каталог — 700.
Образ не содержит `.env`, ключ поставщика или служебные файлы macOS.
Заполнить переменные по `.env.example`; случайный пароль Postgres должен
содержать только символы, безопасные в URL (например, hex).

Из `server/deploy`:

```sh
docker compose config --quiet
docker compose up -d --build
docker compose ps
curl --fail https://v2202609418891520218.quicksrv.de/v1/health
```

Не выводить `docker compose config` без `--quiet`: он раскрывает секреты.
Не использовать `down -v`: это удаляет БД и данные сертификата.
Обновление: переносить исходники без `.env`/`node_modules`/`._*`, затем
выполнить `up -d --build`. База хранится в отдельном томе.

## Бюджет

Пользователь разрешил 500 ₽/сутки. На 14.11.2026 публичный базовый тариф
AvtoVinCod `/gos2vin` — 8 ₽ за найденную машину:
https://avtovincod.ru/ (каталог API). Бесплатный тест — `Т000ТТ00`.

При этом тарифе `LOOKUP_DAILY_FOUND=62` резервирует максимум 496 ₽ за
скользящие 24 часа. Неизвестный исход/таймаут также занимает резерв;
подтверждённое отсутствие данных освобождает его. При изменении тарифа
пересчитать предел вниз. Per-install лимит — 10 попыток за 24 часа.

**14.11 вечером: бюджет настроен, но поставщик недоступен с VPS.**
`LOOKUP_DAILY_FOUND=62`, `LOOKUP_DAILY_BUDGET_RUB=500`,
`LOOKUP_UNIT_COST_KOPEKS=800`. Код берёт минимум ручного предела и
floor(бюджет × 100 / цена); неверные значения останавливают запуск.
Без заданного бюджета deployment по умолчанию отключает платные вызовы.
В кабинете AvtoVinCod владелец сохранил 500 ₽/день и 5000 ₽/месяц;
оба значения подтверждены заголовками ответа бесплатного теста с Mac.
Баланс пополнен владельцем до 200 ₽. Реальный поиск через VPS не завершён:
TLS к api.avtovincod.ru зависает после ClientHello ещё до авторизации.
Другие HTTPS-сайты с VPS доступны, OUTPUT ACCEPT, DNS совпадает с Mac.
Бесплатный и реальный тест через VPS вернули 503, расходов не подтверждено.
Нужна диагностика доступа 202.61.225.12 у поставщика; обход через Mac
или незашифрованная передача ключа не настраивались.
Лимит самого поставщика допускает превышение последним/параллельными
запросами, поэтому он дополняет резерв Beepy, а не заменяет его:
https://avtovincod.ru/docs/limits/

API-токен установки пока не привязан к Apple ID. Две сохранённые машины
ограничивает iOS; серверная квота на Apple-аккаунт ещё не реализована.
Release 11 остаётся без публичного API. Включение требует новой сборки и
обновления политики/декларации Apple с учётом сервера в Германии.

## Резервная копия перед включением

Ручная копия `/opt/beepy/backups/before-budget-20261114.dump` создана перед
изменением конфигурации; восстановление в отдельную тестовую БД проверено.
Автоматические резервные копии пока не настроены. Потеря журнала квот
сбросит учтённый расход.
Пример ручного снимка в защищённый каталог (имя файла каждый раз новое):

```sh
umask 077
mkdir -p /opt/beepy/backups
docker compose exec -T db pg_dump -U beepy -d beepy -Fc > /opt/beepy/backups/beepy-before-enable.dump
```

При восстановлении после потери журнала оставить общий лимит 0 минимум
24 часа либо восстановить весь актуальный журнал, чтобы не расходовать
тот же бюджет повторно. Секреты не включать в Git и не передавать в iOS.
