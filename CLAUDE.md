# Beepy — руководство для агента

iOS-приложение для автомобилистов: **диагностика машины и трекинг ТО**.
Раздел «Ошибки» слушает звук мотора и возвращает находки, раздел «Машина»
ведёт историю обслуживания и считает, когда следующее ТО.

SwiftUI, таргет iOS 17.0, проект `Wheelly.xcodeproj`, схема `AppMVP`, бандл
`com.vladislavkotyrev.appmvp`, на устройстве подписан **Beepy**.
Дизайн — Figma `9GXgWezTGI6TjklsnuBns2`, воспроизводится попиксельно.
Данные пользователя лежат локально в SwiftData: приложение для РФ, по 152-ФЗ
персональные данные телефон не покидают, пока нет сервера в России.

## Порядок работы

1. **Типы первыми.** Состояние, у которого нельзя выразить неверную
   комбинацию, не нуждается в тесте на эту комбинацию: багу негде жить.
2. **Логика — вне вью, в `AppMVP/Core/Pure/`.** Всё, что решается без SwiftUI,
   SwiftData, диска и сети, живёт там отдельным `enum` без состояния:
   `PlateFormat`, `ServiceMath`, `NumberFormat`. Модели SwiftData туда не
   заходят — функции берут значения, а переходники `Car → значения` остаются
   во вью. Логика, оставленная в `body`, — логика, которую никто не проверит.
3. **Между числом и единицей — неразрывный пробел** (`\u{00A0}`), как и внутри
   разрядов: «9 000 000 км» не должно разрываться переносом. Держится
   `tools/check-typography.py`.
4. **Числа из макета — в токены, не в вёрстку.** В компоненте не должно быть
   литерала, кроме строки. Токены живут в `Core/Design/Theme.swift`.
5. **Менять смысл функции — сначала прочитать всех вызывающих** (`grep` по
   имени). Общий `photoItems` на две формы уже открывал чужую модалку.
6. **Документы последними** и только те, что не могут разъехаться с кодом.

## Сборка

**Xcode на месте** (26.6, `xcode-select -p` → `/Applications/Xcode.app`), сборка
и симулятор работают отсюда. Раньше здесь стояли Command Line Tools и этот
раздел запрещал обещать сборку — запрет снят, но правило под ним осталось: не
заявлять собранным то, что не собиралось. Установка Xcode — [docs/XCODE_SETUP.md](docs/XCODE_SETUP.md).

```bash
xcodebuild -project Wheelly.xcodeproj -scheme AppMVP -sdk iphonesimulator \
  -configuration Debug -destination "id=<UDID>" \
  -derivedDataPath ~/Library/Developer/Xcode/DerivedData/beepy build
```

**Не собирать внутрь папки проекта.** Проект лежит на Рабочем столе, тот
синхронизируется с iCloud Drive, файловый провайдер вешает на бандл
`com.apple.FinderInfo`, и подпись падает с `resource fork ... not allowed`.
Отсюда `-derivedDataPath` наружу. Собрали внутрь — `xattr -cr путь/к/Wheelly.app`.

Установка на iPhone и логи — [docs/DEVICE_TESTING.md](docs/DEVICE_TESTING.md).

## project.pbxproj ведётся вручную

XcodeGen не установлен. `project.yml` — **справочный**, он уже разошёлся с
реальным проектом, и `xcodegen generate` затрёт настоящий файл.

Новый `.swift` прописывается в **четырёх** местах: `PBXBuildFile`,
`PBXFileReference`, `children` своей группы, `PBXSourcesBuildPhase`.

- Свободный префикс ID **проверить грепом, а не угадать.** Совпадение с чужим
  объектом Xcode ловит падением `unrecognized selector`, которое ничем не
  намекает на коллизию.
- После правки — `plutil -lint Wheelly.xcodeproj/project.pbxproj`.
- Проверить, что всё сошлось: `.claude/hooks/require-journal.sh --audit`.

## Как проверять (обязательный минимум)

1. Сборка без предупреждений.
2. Консоль симулятора: **нет `cycle detected`**.
3. **Скролл жив**: временно `.defaultScrollAnchor(.bottom)` — кадр должен
   показать низ страницы с «Удалить авто». Этот замер один раз поймал
   регрессию, которую не видела попиксельная сверка.
4. Попиксельная сверка с рендером Figma. Ориентиры: главный экран ~8.7/255,
   экран добавления 5.9/255, шторка «Это ваш автомобиль?» 15.2/255.
   Таббар считать **отдельно**: у нас свой `FloatingTabBar` против системного
   компонента iOS 26 в макете, он один даёт 63/255 и тянет любое число вверх.
5. Симулятор перед съёмкой **перезагружать**, кадр снимать **до** остановки
   процесса, прокрутку сбрасывать. На каждом из трёх пунктов уже были ложные
   результаты.
6. **Рендеры Figma перекачивать**, если дизайн правился. Дважды сверялся с
   устаревшими и объявлял совпадение там, где его не было.

Инструменты сверки — `diffimg`, `rowsx`, `crop2`, `fast2`, `fine2` — лежат в
`~/.claude/jobs/f6310428/tmp/` вместе с исходниками на Swift. Каталог временный:
если его нет, инструменты собираются заново из тех же исходников.

Что можно прогнать **без Xcode**, прямо на любой машине с исходниками:

```bash
./tools/run-pure-checks.sh
```

Собирает `Core/Pure/*.swift` вместе с `tools/pure-checks/main.swift` через
`swiftc` из Command Line Tools и прогоняет 39 проверок. Заодно это граница
слоя: затащишь в `Core/Pure` SwiftUI или SwiftData — прогон перестанет
собираться, и узнаешь об этом сразу, а не через неделю.

```bash
python3 tools/check-typography.py
```

Русская типографика в строках интерфейса: тире вместо дефиса, диапазоны,
прямые кавычки, многоточие тремя точками, двойные пробелы, разрыв между числом
и единицей. Проверяются только литералы с кириллицей (и с «₽»): комментарии и
идентификаторы на экран не попадают. Интерполяция схлопывается в один символ —
иначе «\(grouped(mileage)) км» выглядит строкой без чисел, а это и есть самое
частое нарушение здесь. Ошибки валят прогон, предупреждения — нет: их фикс
может разойтись с макетом и проверяется сверкой, а не грепом.

```bash
python3 tools/check-project.py
```

Читает `project.pbxproj` как объектный граф: висячие ссылки, дубли в фазе
компиляции, `.swift` мимо проекта, ссылки на удалённые файлы, несуществующие
каталоги групп. Xcode на битом проекте падает сообщениями, которые не намекают
на причину, — этот разбор называет причину.

**Не заявлять, что работает, без проверки.** Прогнать, снять кадр, замерить —
или сказать прямо, что не проверено. Это правило дороже остальных: тестов нет,
жесты проверяет человек, и непроверенное утверждение здесь никто не поймает.

## Ограничения окружения

- **Тапать по симулятору нельзя**: macOS не даёт `/usr/bin/osascript` доступ
  в «Универсальном доступе». Любое поведение жестов проверяет пользователь.
- **Гироскопа в симуляторе нет** — блик по наклону только на устройстве.
- **Микрофон в симуляторе выдаётся командой**, системный запрос нажать нечем:
  `xcrun simctl privacy <UDID> grant microphone com.vladislavkotyrev.appmvp`.
  Иначе уровень молча остаётся нулевым.
- **Патч вкладки без посева машины ничего не проверяет**: при пустой базе
  `RootView` показывает `AddCarView`, до `CarMainView` дело не доходит.
- **Профиль бесплатного Apple ID живёт 7 дней**, потом переустановка.
  Sign in with Apple и push на нём не работают.
- **Git по этой папке медленный**: она в iCloud Drive, и `git log` с
  pathspec по всей истории уходит за две минуты. Индексные команды
  (`git diff --cached`, `status`) быстрые.
- **`VehicleLookupKey.swift` под `skip-worktree`**: в рабочей копии лежит
  настоящий платный токен, в git — версия с пустой строкой, потому что
  репозиторий публичный. Правки этого файла git не видит; менять его код —
  через `--no-skip-worktree`, без токена в коммите.

## Три грабли, которые дороже всех

Полный список — в [docs/TRAPS.md](docs/TRAPS.md). Эти повторялись:

- **`@State`, который пишут на каждом кадре прокрутки, ломает сам скролл.**
  `body` начинает зависеть от позиции, `ScrollView` пересобирается каждый
  кадр, экран уезжает сам. Позиция не должна становиться состоянием вью:
  прозрачность считает `.visualEffect`, значение для жеста лежит в ссылочной
  коробке, которую никто не наблюдает.
- **Чтение окна UIKit в `body` даёт цикл AttributeGraph** и выглядит как
  «нажатия не работают». Размеры экрана — из `DeviceMetrics` через окружение.
- **Погашенная в ноль вьюха продолжает принимать касания.** Рядом с
  `.opacity(visible)` обязателен `.allowsHitTesting(visible > 0.5)`.

следующие шаги того же дня после уже закоммиченной записи.

Заслонка **падает открытой**: нет `jq`, не репозиторий, ошибка git — пропуск.
