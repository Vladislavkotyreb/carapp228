# Beepy для бизнеса — набросок CRM

Кабинет автосервиса по ту сторону приложения Beepy: заявки, дашборд,
сотрудники. **Набросок интерфейса**: данные тестовые и живут в браузере
(localStorage). Персональные данные клиентов по 152-ФЗ должны лежать на
сервере в РФ — до него это прототип, а не система учёта.

## Что есть

- **Заявки** — список на аккордеоне Fluid Functionalism. Строка: номер,
  клиент и машина, кратко о проблеме, источник, статус, исполнитель.
  Раскрытие: у заявки из приложения — итоги прослушивания (находки с
  уверенностью и советом), у заявки с сайта-визитки — комментарий клиента и
  удобное время. Справа контакты, назначение сотрудника и статус.
  Назначили исполнителя на новую заявку — она сама уходит «В работу».
- **Канбан** — второй вид заявок, по образцу доски Jira (рефы на Mobbin:
  Jira board со swimlanes). Серые колонки-статусы с заголовком капсом и
  счётчиком; над доской — цветные аватары сотрудников как фильтр (плюс кружок
  «без исполнителя») и группировка: нет / исполнитель / источник. В дорожках
  исполнителей перенос карточки в чужую дорожку переназначает заявку, как в
  Jira; «Без исполнителя» — последней. Карточка: суть проблемы, метка машины,
  удобное время (для записи с сайта), в подвале источник и №, красный флажок
  у открытой заявки старше суток, аватар исполнителя. Клик открывает заявку
  целиком — это же путь для клавиатуры и тачскрина. Вид и группировка
  запоминаются.
- **Дашборд** — новые, без исполнителя, в работе, готово за неделю; заявки,
  ждущие исполнителя (кнопка ведёт прямо в заявку); откуда приходят люди;
  загрузка сотрудников; с чем приходят по итогам прослушивания.
- **Сотрудники** — три вкладки.
  - «Сотрудники»: роль, оплата, смены за месяц, открытые заявки, «на смене».
    Клик по имени — правка роли и оплаты.
  - «Табель и оплата»: месяц, строка — человек, клетка — день; клик отмечает
    смену (будущие дни закрыты). Справа — смены и «к выплате» с расчётом во
    всплывающей подсказке, сверху — фонд оплаты. «На смене» — это отметка
    сегодняшнего дня в табеле, а не отдельный флаг.
  - «Роли»: свои роли сверх четырёх стандартных, переименование на месте,
    удаление — только пустой роли.
  Оплата — ставка за смену (смены × ставка) или месячный оклад (пропорционально
  дням от нормы, не больше оклада). Норма — будни пн–пт без праздников;
  переработка и выходные по двойному тарифу не считаются. Расчёт —
  `src/data/payroll.ts`.

Источников заявок два, и тип это держит (`RequestPayload` в
`src/data/types.ts`): у заявки с сайта не бывает находок, у заявки из
приложения — комментария из формы.

## Запуск

```bash
npm --prefix crm install
npm --prefix crm run dev -- --port 5188
```

Или из Claude Code — конфигурация `crm` в `.claude/launch.json`.

## Устройство

- Vite + React 19 + TypeScript + Tailwind 4, shadcn с Base UI.
- Компоненты — реестр `@fluid` (https://www.fluidfunctionalism.com), вариант
  Base UI: `components.json` смотрит в `/r/base/{name}`. Бейдж, карточка,
  поле ввода и таблица существуют только в общем варианте — они ставились по
  полному адресу `/r/{name}.json`.
- `src/components/ui/*` — код библиотеки, не правится. Одна замена:
  `card.tsx` импортирует `next/link`, у нас он подменён `src/lib/link.tsx`.
- `src/data/` — типы, тестовые данные, хранилище (редьюсер + localStorage) и
  подсчёты дашборда чистыми функциями.
- `node_modules` — символическая ссылка на `node_modules.nosync`: репозиторий
  лежит в iCloud Drive, а тысячи файлов зависимостей ему синхронизировать
  незачем.

## Грабли библиотеки, на которые уже наступили

- `AccordionGroup` по умолчанию шириной `w-72` — под боковую панель. Для
  списка ему нужен `className="w-full"`.
- Триггер аккордеона кладёт содержимое в `inline-grid` с колонкой по ширине
  содержимого: колонка `minmax(0,1fr)` внутри схлопывается в ноль. Лечится
  `[&>span:first-child]:grid-cols-[minmax(0,1fr)]` на триггере.
- Управляемое `value` у `AccordionGroup` щелчок обходит: строка раскрывалась,
  а `onValueChange` не вызывался. Поэтому раскрытие отдано группе
  (`defaultValue` + `key` для перехода с дашборда).
- `Switch` рисует `label` видимым текстом; в таблице он скрыт
  `[&>span:last-child]:sr-only`, для скринридера остаётся.
